コア = クラス（行数で大きさ）／ 球 = フィールド、八面体 = property、立方体 = クラス変数、琥珀色 = __init__ 以外でも書き換わる
ゲート = メソッド（球面上にソース順で上から並ぶ。行数で大きさ、10 行ごとに目盛り 1 本）／ 切れ目のある明るいリング = public、青緑 = internal、暗い青 = class-local、二重リング = 特殊メソッド
外側の弧 = 同じクラス内の呼び出し（光の粒が流れる向き）／ 内向きの線 = 値の参照（水色 = 読み、琥珀色 = 書き）
ドラッグで回転、ホイールで拡大、ゲートに触れると関係する線だけが光る
